# Quadra — Rodízio de vôlei

Aplicação local para cadastrar jogadores, escolher um sistema de jogo e organizar as seis posições do rodízio.

## Como usar

Abra `index.html` em um navegador. Os jogadores, as escalações e o sistema selecionado ficam salvos no Local Storage do navegador.

## Recursos

- Cadastro, edição e remoção de jogadores com funções principais e secundárias.
- Escalações independentes para saque do time e saque adversário, com opção para copiar uma para a outra.
- Visualização de seis rodadas para os sistemas 5×1, 4×2, 6×0 e 6×0 LF.
- Quadra representada com a rede à frente nas posições 4, 3 e 2 e o fundo nas posições 5, 6 e 1.

O projeto usa HTML, CSS e JavaScript sem dependências ou servidor.
